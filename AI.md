# Uso de inteligência artificial

Este projeto foi desenvolvido com apoio de um assistente de IA integrado ao VS Code (Copilot SDK).

## Como a IA foi utilizada

- Apoio na revisão da estrutura e na preparação do projeto Vite para a entrega.
- Implementação assistida do painel React de iniciativas comunitárias, hooks, integração demonstrativa com JSONPlaceholder e testes automatizados.
- Apoio na revisão da documentação e na execução de build e testes.

## Validação e limites

As alterações foram conferidas no código e validadas com `npm test` e `npm run build`. A API escolhida é apenas demonstrativa e não persiste alterações. Os dados climáticos, perfis e atividades já existentes no site também são fictícios. Não foram implementados autenticação, conexão com totens nem coleta real de dados pessoais.

O uso de IA não substitui a revisão dos integrantes do grupo. O grupo deve revisar o código, confirmar que a implementação corresponde ao PDF da disciplina e atualizar este arquivo se outras ferramentas ou usos de IA forem adicionados.
